# Decisiones funcionales pendientes

Estas decisiones no están confirmadas por la especificación y se mantienen abiertas:

1. **Vista rápida:** se muestra el número del legajo junto con algunos datos útiles, pero falta confirmar el resumen definitivo.
2. **Descargas:** la implementación actual ofrece vista previa en línea. Falta confirmar si se habilita descarga explícita.
3. **Papelera:** no implementada; confirmar si se requiere recuperación de eliminados.
4. **Columnas:** la tabla muestra todas las columnas especificadas; no se implementó personalización.
5. **Transiciones:** los siete estados son fijos y se permite seleccionar cualquiera. No se impusieron reglas de transición.

Las decisiones sobre descargas y papelera pueden cambiar el manejo de archivos y eliminaciones. El resto no bloquea el trabajo principal.
